## 中文文案

全部内置界面、提示、错误与速度单位统一中文；应用固定简体中文，使英文系统下的复制、粘贴、全选及弹层关闭等控件也使用中文。系统和网络异常经中文映射处理，不把英文异常、文件路径或堆栈直接展示给用户。坐标系代号和外部地点名称保持原有含义。

## 定位能力边界

本项目仍使用安卓模拟定位源。系统各定位源的校验通过，只证明系统读回目标附近的模拟坐标，不保证第三方应用最终采用它。无线网络、基站、应用自有缓存或独立定位策略无法据此次研究宣称已经接管；免系统提权的能力边界保持明确。


## 第二轮：功能延伸与算法审查（1.4.0）

多个 agent 分别研究竞品资源、原生引擎、坐标与持久化、路线工具、地点管理、备份安全，再由独立 agent 做集成复核。参考资源中能确认历史地点搜索、历史路线搜索及方向锁定等功能意图；没有证据证明全部免会员可用，因此本项目采取独立本地实现，不引入对方账号、会员或系统提权链路。

已实现：

- **路线工具**：反转、闭合、按半径与方向生成圆形测试路线，均支持一次撤销，生成后不自动启动。环线在写入所用的球面坐标中计算，再转换为地图草稿；不依赖道路服务，不宣称沿道路或避障。
- **本地管理**：常用/最近按名称、地址、坐标筛选，已存路线按名称筛选；同名覆盖与删除需确认，最近记录删除持久化。
- **路线引擎**：大圆插值、日期线短路径、极点三维向量计算；循环包含回程段，往返转向正确，暂停和结束速度归零，变速不重算过去耗时，单程结束保留停止入口。
- **一致性**：地图里程与原生按实际写入点量距，统一球面半径6371008.8米；GPS、网络和融合源每一轮使用相同坐标、精度与采样时间，移除无依据的独立抖动。
- **摇杆**：杆量与实际经过时间决定路程，移除旧单步5米上限；系统速度和朝向同步，松手、切后台归零，空闲关闭不会打断路线。
- **检测与缓存**：以服务实际执行坐标校验，未应用草稿不造成误报；旧异步检测不能在停止后恢复运行状态；检测仅读近期缓存，停止后的真实定位排除迟到模拟回调。
- **数据边界**：拒绝非有限坐标和非法参数，修正度分秒分组，备份先完整预检；写入返回失败明确报错并触发恢复，恢复失败如实告知，不声称多项存储原子性。

定位年龄采用开机后的单调时间，而非可能被手动修改的日历时间；系统模拟标记保持 Android 的语义。[Android Location官方文档](https://developer.android.com/reference/android/location/Location)

### 精度和仍存在的边界

球面模型用于内部一致的模拟，并非WGS-84椭球测绘。毫米或厘米断言衡量同一数学模型的数值误差，不代表设备真实精度。[PROJ官方测地线说明](https://proj.org/en/stable/geodesic.html)

GCJ公开近似公式采用项目既有矩形适用区。在东界样本WGS `(20,137.83469)`，前向加偏后的点跨出适用区，按既有范围外不偏移策略反解有约442.427米歧义。单个未知来源坐标不足以分辨是否跨界，本轮没有擅自改变境外坐标语义，也不宣称全球精确反解。完整定量记录位于工作区 `outputs/fake-location-reference/round2-coordinate-algorithms.md`。

第三方应用是否采用系统模拟源仍受自己的网络定位、缓存和模拟标记策略影响。本轮验证系统接口与本项目交互，没有以模拟器结果代替微信、高德真机交替及不同WiFi环境的兼容结论。
