# 路线页界面约定

本轮依据用户截图重排主次，目标是让地图和当前任务优先，参数按需展开。

## 主界面

- 顶部使用一条统一工具栏：返回、路线模拟、撤销、更多；不再堆叠独立圆形按钮或把路线信息挤在截断标题里。
- 底部只保留路线概览、简短状态、参数摘要与主要操作。里程为主要数值，时间和点数为次要信息，速度只展示一次。
- 运动方式、速度、步频、步幅、播放方式收进“路线设置”；点击摘要整行或“调整”都应容易发现入口。
- 终点状态用“终点保持中”说明，停止入口始终保留；恢复真实定位的含义不能只靠颜色表达。
- 添加起终点、拖动和重选中的必要提示按状态出现，不把完整操作说明长期铺在地图上。

## 工具与参数

- 反转、闭合、环线、重选起点、保存、载入、清空和回到路线收进工具面板，使用明确中文名称。
- 破坏草稿的清空需确认；操作继续沿用原撤销与运行保护。
- 设置面板先编辑临时值，“完成”才应用，取消保留原参数。运行期间禁止改变当前路线参数。
- 参数页可滚动，窄屏、大字号和键盘展开时均保留完成与取消入口。

## 视觉与可用性

沿用项目青绿色主题、Android中文字体和原图标系统，不引入字体服务或新依赖。工具栏约56逻辑像素，图标点击区域至少44逻辑像素；主界面底栏尽量控制在约180～210逻辑像素，动态状态与大字号时允许自然增高。

密集路线的普通采样点仅保留8像素视觉圆点，起终点和选中点突出；手势区域不跟着缩小。允许继续放大既有底图编辑细点，不请求超过原生层级的瓦片。

验证采用360逻辑像素宽和1.6倍文本缩放的交互回归，并在Android模拟器查看实际画面。设计检索仅作参考；没有照搬其网页漏斗、金色配色或英文字体建议。
