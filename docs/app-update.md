# 1.4.2应用更新

## 参考与取舍

只读参考了codex-pocket和zl-study-hub完整源码，没有改动这两个项目，也没有复制其账号、签名或部署配置。

- codex-pocket：参考Android AppUpdateController/UpdatePolicy的任务状态、下载进度、缓存安装、授权返回与签名检查，以及AppUpdatePanel的阶段展示。
- zl-study-hub：参考AppUpdatePlugin和nativeUpdater/useUpdate的进度回传、主动检查、静默启动检查以及安装衔接。
- 本项目继续使用Flutter与现有Android桥，不引入WebView刷新、Electron更新或额外依赖。

## 修复

旧流程把版本读取放在真实定位之后，首次可能等待20秒；版本读取失败时仍可能把“未知”判为“最新”。设置弹层还持有独立的旧状态。下载没有进度，取消/重试不完整，每次重删安装包，打开未知来源设置后不能续装；下载自动跟随跳转也未逐跳核对来源。

新版在首页初始化时独立读版本、检查清单。Pages、原始文件和仓库接口并发核对，统一8秒时限，采用最高构建号；同版本摘要冲突或全部失败保留错误。更新面板与设置共享一个状态源，明确检查、下载、校验、待安装、授权、系统安装、取消和错误。

APK下载限定同一发布仓库，逐跳验证HTTPS来源，受控重试与取消断连；大小、摘要、包名、递增版本与签名全部校验。安装前再次检查缓存，未知来源授权后继续安装，系统安装器取消后可直接重试。系统安装器打开不等于更新完成。

## 文案

删除设置中的未提供功能介绍、系统提权长段、使用提示卡、坐标转换装饰页脚。搜索密钥和备份各保留一句；检测保留逐源证据与复制入口，长技术介绍压成短说明。坐标输入、搜索占位和授权提示同步精简，错误仍给出必要下一步。

## 验证方式

新增模型、状态、下载传输、首页集成和小屏测试。完整安装链另用同一新版源码构建本地低构建号升级验证客户端，下载线上已发布的更高构建号安装包；该验证客户端单独保留且不作为正式1.4.2发布。正式包仍是pubspec声明的1.4.2（16），两者不混用验收或摘要。


独立复核另修复了缓存校验失败卡住、系统清理缓存后仍可安装、仅恢复版本元数据时重试不执行、旧清单覆盖较新已验证缓存四个状态边界。没有通过移除校验、接受任意镜像或更换签名解决下载问题。

当前网络下约57MB在线APK下载较慢。设备已观察到真实字节进度，并验证取消、关闭重开面板和设置页同步；安装授权与缓存重试使用另行标注的调试验证客户端和已发布包作为缓存样本验证。缓存样本由测试工具放入应用沙箱，随后仍由生产控制器执行大小、摘要、包身份、版本与签名校验，不将该测试宣称为完整在线下载安装。
