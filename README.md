# 虚拟定位（Android）

一个仅面向 Android 的 Flutter 虚拟定位应用。地图使用 GCJ-02 坐标（高德瓦片），向系统 GPS 写入 WGS-84 坐标；应用可以直接从 GitHub 发布仓库检查、下载并安装最新版。

## 使用方式

1. 在手机“开发者选项”中把“选择模拟位置信息应用”设为“虚拟定位”。
2. 打开应用，搜索地点、输入坐标或点击地图选择目标位置。
3. 点击“开始模拟”；需要停止时点击“停止”即可恢复真实定位。
4. 应用会在设置里显示当前版本。发现新版本后可以直接下载并交给系统安装器。

## 功能

- **地图**：高德标准图（含建筑、绿地、POI 标注）、卫星图、简洁路网图三种底图，2 倍高清瓦片。
- **搜索**：按“高德 → 百度 → OSM”顺序自动降级，结果带来源标识与距离，可长按直接收藏。
  - 在设置里填写高德“Web 服务”Key 后，搜索改用高德开放平台，POI 与高德地图完全一致，并支持高德逆地理。
  - 未填 Key 时使用百度地图网页数据，国内 POI 覆盖好；再由 Photon（OSM）兜底。
  - 输入过程中有联想补全，减少“名称不完整搜不到”的情况。
- **坐标输入**：底部「坐标」打开独立面板，纬度、经度分开填，起手就用当前目标点预填，改几位数字即可。
  - 支持十进制（`39.908722, 116.397499`）、度分秒（`39°54′31″N 116°23′51″E`）、带 N/S/E/W、`geo:` 链接、`gcj: / wgs: / bd:` 前缀和全角符号；纬度经度写反了会自动交换。
  - 坐标系可切换 GCJ-02 / WGS-84 / BD-09 解释，识别后同时列出三种坐标系的坐标，避免“填了却偏 500 米”。
  - 支持从剪贴板一键粘贴、反查地址；搜索框里直接粘坐标回车同样能定位。
  - 搜不到的地方（小店、工地、新楼盘、野外点位）直接填经纬度最稳。
- **常用地点**：一键把当前选点存为常用地点，可重命名、删除、复制坐标；「最近」自动记录模拟历史（最多 30 条）。
- **精调**：方向键按 1 / 10 / 100 米微调目标点，地图与坐标实时联动，模拟中会同步下发新位置。
- **签到范围圈**：以目标点为圆心画出 100 / 200 / 500 米圆，便于判断是否落在签到范围内。
- **定位**：读取 GPS/网络/融合定位，20 秒内取精度最好的一次，界面显示精度与来源；定位不准时提示并可直接跳转定位设置。
- **坐标系**：界面显示可切换 GCJ-02 / WGS-84 / BD-09；“写入系统坐标”可在 WGS-84 与 GCJ-02 之间切换，用于修正个别 ROM 或应用造成的约 500 米偏移。
- **生效检测**：底部「检测」会同时读取模拟服务状态与系统真实读回的位置，直接告诉你模拟是否真的全局生效。
  - 逐项显示：模拟服务是否运行、坐标已推送多少次/多久前、接管了哪些定位源（gps / network / fused）、系统读回坐标与精度、系统是否标记为 mock、与目标点的偏差。
  - 判定四种状态：未设为模拟位置应用、服务没有在推送、系统仍返回真实定位、已生效；每种状态都给出对应的处理办法。
  - 支持「重新推送」和「打开高德」两个按钮，改完直接跳到高德验证。
  - 开始模拟后会自动校验一次，没生效就会弹出提示；模拟过程中每 6 秒检查服务是否被系统杀掉。
- **路线模拟**：在地图上点出途经点连成路线，按设定速度沿路线移动；单程 / 循环 / 往返三种走法，可暂停、继续、停止，进度与已走距离实时显示；路线可命名保存、下次一键复用。
- **运动方式**：步行 / 跑步 / 骑行 / 驾车 / 飞行 / 自定义六档；步行和跑步按「步频 × 步幅」换算速度（120 步/分 × 0.7 米 ≈ 1.4 m/s），速度与朝向会写进系统定位。
- **摇杆移动**：地图右侧开启摇杆，按住拖动即可像走路一样实时移动，松手停下，速度跟随当前运动方式。
- **悬浮控制条**：开启后可在高德等其它应用上看到「移动中 / 已暂停 · 速度 · 进度」，可直接暂停、继续或一键回到真实位置（需悬浮窗权限）。
- **模拟参数**：位置更新频率 100 / 200 / 500 / 1000 毫秒可调（微信建议 100~200），模拟精度 ±3 / 5 / 10 / 20 米可调。
- **数据备份**：常用地点、保存的路线和全部设置可导出到剪贴板，换机时导入即恢复。

> WiFi 模拟、基站模拟、独立模拟（只对某个应用生效）、反检测、Root 隐藏这几项在 Fake Location 里依赖 Root / Xposed，
> 免 Root 方案无法真正实现，因此本应用没有提供——设置页里也写了这条说明。
>
> **会被钉钉/飞书这类应用识破吗？** 系统投递模拟位置时会打上 `FLAG_MOCK` 标记，
> 有定位权限的应用一行代码就能读到，免 root 去不掉（连 `adb shell cmd location` 也只提供 test provider，
> 唯一的非 mock 入口在 HAL 层）。对微信 8.0.34 与飞书 8.5.4 做过静态分析：
> 微信读的是 Android 6 以前的旧开关、现代系统上基本失效，飞书则通过内置的高德 SDK 直接调
> `isFromMockProvider()` 会拿到 true。详细证据与复现脚本见
> [docs/mock-detection-analysis.md](docs/mock-detection-analysis.md)。

## 常见问题

- **其它应用里位置没变**：先点底部「检测」看系统到底有没有接管位置。
  - 显示“未设为模拟位置应用”：到 开发者选项 →「选择模拟位置信息应用」→ 选「虚拟定位」，再点开始模拟。
  - 显示“模拟服务没有在推送”：服务被系统清理了，点「重新推送」，并在电池设置里允许后台运行。
  - 显示“已生效”但高德还是原位：打开高德后**点一下右下角的定位按钮**（地图不会自动跟随），
    或把高德从最近任务里划掉重新打开；再不行就把高德的位置权限从“大致位置”改成“精确位置”。
- **提示不在签到范围内**：先用搜索定位到具体出入口，或用「微调」对齐签到点，并打开 200 米范围圈确认。
- **搜索不到地点**：先看联想补全；仍不行时在设置里填写高德 Key，数据与高德地图同源。
- **提示定位不可用**：检查定位权限与系统“位置信息”开关，室内可到窗边重试。

## 安装构建包

发布版使用 Flutter 默认 Android 调试签名，以便与最初交付的安装包保持相同签名、支持覆盖更新。这个签名适合个人直装分发；如需上架应用商店或公开大规模分发，应先配置独立的正式签名，并让所有已有用户卸载旧版后重新安装。

```bash
flutter pub get
flutter analyze
flutter test
flutter build apk --release
```

产物位于 `build/app/outputs/flutter-apk/app-release.apk`。该目录已加入 Git 忽略规则。

## 发布

先在 `pubspec.yaml` 提高 `version` 和 `+` 后面的整数构建号，再运行：

```bash
node tool/release.mjs
```

脚本会执行分析、测试、安卓打包，把最新 APK 以固定文件名发布到同账号的 `fake-location-releases` 公共仓库，更新 `update.json` 和下载页，删除发布仓库中的旧 APK，最后清理本项目 `build/` 和 Gradle 输出目录。应用内下载使用 GitHub Pages 地址，获得更稳定的下载速度。

可用参数：

- `--dry-run`：完整构建并生成发布文件，但不提交、不推送，也不清理。
- `--no-push`：只提交发布仓库，不推送。
- `--skip-tests`：跳过 `flutter test`，其余检查和打包照常执行。

可通过 `RELEASE_REPO_DIR` 指定已克隆的发布仓库目录：

```bash
RELEASE_REPO_DIR=/path/to/fake-location-releases node tool/release.mjs
```
